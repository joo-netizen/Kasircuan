📥 Impor spreadsheet Excel / CSV

Pindahin data dari spreadsheet lama ke Kasir Cuan. Mendukung .xlsx, .xls, dan .csv. Untuk spreadsheet dengan 2 sheet, pilih sheet dan jenis datanya satu per satu.

Sebelum impor, download backup dulu. Impor menambahkan data ke data yang sudah ada (bukan mengganti). Cek pratinjau dan pilih jenis data yang sesuai agar tidak dobel.

Cadangan data

Download backup JSON secara berkala. Untuk memulihkan data, pilih file backup JSON yang dibuat dari aplikasi ini.

Penting: versi online menyimpan data utama di database cloud. Tetap download backup JSON secara berkala. Koneksi internet diperlukan untuk sinkronisasi.
